## Key finding: mid-session command registration

The most critical gap (0/3, all criteria failing for mid-session-user) was that nowhere in the docs did we explain that Claude Code only registers slash commands at session start. This is the exact scenario that triggered this session — the harness was invoked manually because `/code-beta` wasn't registered. The fix (Troubleshooting section in README with restart + manual fallback options) addresses the root UX gap.
